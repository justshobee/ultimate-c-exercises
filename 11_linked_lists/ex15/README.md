## 15. Palindrome Check Variants
 
**Description:** Write a C program to check if a singly linked list is a palindrome or not.
 
**Test Data and Expected Output:**
```
Original Singly List:
1 2 3 4 5
Linked list is not a palindrome.
 
Original Singly List:
1 2 2 1
Linked list is a palindrome.
 
Original Singly List:
MADAM
Linked list is a palindrome.
```
