## 17. ft_sorted_list_merge
 
* **Description:** Create the function `ft_sorted_list_merge`, which integrates the elements of a sorted list `begin2` into another sorted list `begin1`, so that `begin1` remains sorted in ascending order.
* **Directory:** `ex17/`
* **Files to submit:** `ft_sorted_list_merge.c`, `ft_list.h`
* **Authorized:** None
* **Function Prototype:** `void ft_sorted_list_merge(t_list **begin_list1, t_list *begin_list2, int (*cmp)());`
* **Usage note:** `cmp` is used as `(*cmp)(list_ptr->data, list_other_ptr->data);`.
