## 09. ft_list_foreach
 
* **Description:** Create the function `ft_list_foreach`, which applies the function given as an argument to each of the list's elements. `f` should be applied in the same order as the list. The function pointed to by `f` is used as `(*f)(list_ptr->data);`.
* **Directory:** `ex09/`
* **Files to submit:** `ft_list_foreach.c`, `ft_list.h`
* **Authorized:** None
* **Function Prototype:** `void ft_list_foreach(t_list *begin_list, void (*f)(void *));`
