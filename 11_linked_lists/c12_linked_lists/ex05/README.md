## 05. ft_list_push_strs
 
* **Description:** Create the function `ft_list_push_strs`, which creates a new list that includes all the strings pointed to by the elements in `strs`. `size` is the size of `strs`. The first element of `strs` should end up at the end of the list. The first link's address in the list is returned.
* **Directory:** `ex05/`
* **Files to submit:** `ft_list_push_strs.c`, `ft_list.h`
* **Authorized:** `ft_create_elem`
* **Function Prototype:** `t_list *ft_list_push_strs(int size, char **strs);`
