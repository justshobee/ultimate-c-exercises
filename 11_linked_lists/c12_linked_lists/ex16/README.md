## 16. ft_sorted_list_insert
 
* **Description:** Create the function `ft_sorted_list_insert`, which creates a new element and inserts it into an already-sorted list so that the list remains sorted in ascending order.
* **Directory:** `ex16/`
* **Files to submit:** `ft_sorted_list_insert.c`, `ft_list.h`
* **Authorized:** `ft_create_elem`
* **Function Prototype:** `void ft_sorted_list_insert(t_list **begin_list, void *data, int (*cmp)());`
* **Usage note:** `cmp` is used as `(*cmp)(list_ptr->data, list_other_ptr->data);`.
